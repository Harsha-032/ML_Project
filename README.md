# ML GUI Application 🎛️🤖

This project is a **Graphical User Interface (GUI)** built using **Tkinter** that integrates a **Machine Learning model** for making predictions. It provides a simple and interactive way to input data and receive real-time predictions without needing to access the code or command line.

## 🧠 Project Overview

The GUI allows users to:
- Input required features
- Submit data
- Get instant predictions from the trained ML model
- View results in a user-friendly format

## 📁 Repository Structure

```
ML_Project/
└── GUI/
    ├── gui.py          # Main GUI code using Tkinter
    ├── model.pkl       # Pre-trained ML model (serialized)
    └── requirements.txt # Required Python packages
```

## 🚀 Features

- Clean and intuitive user interface using Tkinter
- Integration with a pre-trained ML model (`model.pkl`)
- Instant prediction output based on user input
- Easy to extend or customize

## 🛠️ Technologies Used

- **Python**
- **Tkinter** – for GUI
- **Scikit-learn / Pandas** – for ML model (used during training phase)
- **Joblib or Pickle** – for model serialization

## ⚙️ Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Harsha-032/ML_Project.git
   cd ML_Project/GUI
   ```

2. **Create a virtual environment (optional but recommended)**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows use: venv\Scripts\activate
   ```

3. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

## 🧪 Usage

1. **Run the application**
   ```bash
   python gui.py
   ```

2. **Enter the required input fields** in the GUI window

3. **Click on Predict** to see the output generated by the ML model
